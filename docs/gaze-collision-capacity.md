# Gaze EPA 容量修复（2026-10-23）

10,240 环境、15,000 次更新预算的长跑在完成 8,211 次更新后停止。
第 788,287 个物理批次步报告环境 1401 的 `EPA_HORIZON` 标志 256，
日志明确指出 horizon 容量 24 不足。已有容量配置只处理 `g1/base`，
遗漏了 `ame2-gaze/base`。这次错误不是 CUDA 显存耗尽：记录的更新均为有限损失，
更新时最低空闲显存仍为 12.3436 GiB。

## 修改

- `configure_collision_capacity` 在创建环境及编译碰撞内核前，对
  `g1/base` 和 `ame2-gaze/base` 同时设置 mujoco-warp 的 `types`、
  `collision_convex`、`collision_flex` 三处 EPA horizon 容量为 64，并返回实际值。
  其他任务不修改容量。容量是进程内常量，适用任务应在独立进程中启动。
- `ame-train --preflight` 使用同一配置函数，输出任务和三处容量。
  它解析训练配置，但不创建环境、不选择 GPU、不启动 runner。
- 训练、回放和评估入口对上述两类任务安装实例级物理溢出保护。
  每个物理步保留一帧输入状态，步后检查所有 overflow 标志；发现任何容量溢出即抛出异常，
  不把该步继续交给策略学习。记录失败后，同一实例也不允许继续步进。
- 保护在失败时保存所有异常环境 ID/标志，以及最多 5 个异常环境的前后状态、
  控制输入、外力、基础 MJB 模型、实际展开的随机化模型字段和现存接触信息。
  空 mocap 数组按模型维度跳过，以兼容 mjlab 1.6 的数组桥接。
  即使磁盘写入失败，也会停止仿真；不自动重试训练。

预检命令：

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 uv run --locked ame-train \
  --variant ame2-gaze --phase base --preflight
```

输出的 `scope=configuration_only_not_physics_validation` 表明这是配置预检。
成功输出 64 不等于通过物理压力测试或行为验收。

训练的故障包保存在本次日志目录的 `physics_failures/rank_N/overflow_*/`；
回放和评估默认写入 `logs/<experiment_name>/physics_failures/overflow_*/`。
`metadata.json` 的 `dump_complete` 仅在 NPZ 和 MJB 均保存后变为 true。
`state.npz` 的 `snapshot_env_ids` 给出状态行对应的原环境编号，
`model_*` 是这些环境的实时随机化参数，不应只加载基础 MJB 就声称恢复了原现场。

## 验证范围

远程现有依赖上的完整 CPU 合约测试及新增回归共 64 项通过（5.452 秒），
运行时禁用 CUDA，线程上限为 2。公开训练入口的独立预检也输出三处容量 64。

CPU 回归覆盖容量适用分支、原有 CLI 启动行为和预检不启动训练，
以及溢出停止、单实例隔离、磁盘失败时仍停止、前后状态保存与 MJB/NPZ 重新加载。
实际 mjlab `Simulation` 的两环境 CPU 步进和注入标志 256 的归档路径也经过检查。
注入故障用于测试保护和保存路径，不是制造或重放 EPA 算法故障。

另用实际 mujoco-warp 双椭球碰撞检查临时数组分配，观察到
`epa_horizon.shape == (16, 64)`、CPU 设备、有实际接触、overflow 为零。
这验证设置进入真实碰撞计算；没有修改依赖包。

当时没有保存失败步的完整物理现场，因此不能精确重放那次 Gaze 碰撞，
也不能据此保证 64 覆盖今后的所有姿态。容量使用私有接口，升级依赖时必须重跑相关测试。
新保护只保留一帧设备端状态，正常步无磁盘输出；新增复制和同步开销尚未在
10,240 环境的 GPU 运行中测量。后续仍需同容量 GPU 预检、显存余量和物理压力验证。

本次仅修复和验证工程问题，没有重启正式训练，也没有改变奖励、出生、地形、
课程、优化器或已冻结的训练预算。保留到 `model_8000.pt` 的权重及原失败证据。
原长跑的 10,000 检查点、最终 14,999 检查点和六组最终 GPU 评估没有完成。
后续恢复训练需要重新确认资源独占、恢复点和剩余预算；早期弱行为不作为停训理由，
足量训练后的最终行为仍是结果验收依据。
