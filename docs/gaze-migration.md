当前从零学习诊断预算为 1,001 次更新，约 2.46 亿条环境交互，按容量测量约需 3 小时。更新从 0 编号，因此终点为 `model_1000.pt`。这是早期检查节点，不能作为收敛期限：

- 官方发布 checkpoint 的实际 `iter` 为 2,400，附带 `agent.yaml` 的预算为 3,000；这与源码默认 5,000 不同。
- 官方附带配置每进程 16,000 环境，run name 为 `g1_gaze_4x16k`；四进程全局 64,000 的解释与发布目录一致，但 checkpoint 未包含分布式启动记录。按该解释，当前诊断约为官方发布权重从零训练交互量的 6.67%，不是等预算对照。
- 双方目标朝向、目标采样锥和地图噪声课程都在 48,000 个控制步，即 2,000 次更新时完全展开；当前诊断终点只达到约 50%。
- 单纯延长迭代以匹配总样本数，不会同时匹配 PPO batch、分布式梯度、课程与熵衰减。若检查节点未通过，应结合学习趋势和行为定位原因，不能仅据此宣称迁移失败或盲目延长。

正式训练前仍需自身 checkpoint 的多种子平地/稀疏地形到达与停稳、实际支撑及视频检查，以及 GPU 保存恢复、公开 play/eval 和自身权重导出验证。当前正在按固定预算串行执行，尚无正式训练或自训练行为通过的结论。

## 使用

导入官方发布actor（`joint_order.json`必须包含源策略实际顺序的`joint_names`，不能按字母排序猜测）：

```bash
python -m ame_g1.cli.import_gaze   --checkpoint /path/to/official/model_2400.pt   --joint-order /path/to/joint_order.json   --output /path/to/official_gaze_native_actor.pt

ame-play --variant ame2-gaze --phase base   --checkpoint-file /path/to/official_gaze_native_actor.pt   --num-envs 1 --num-steps 800
```

转换器读取官方checkpoint同目录的`params/agent.yaml`，记录源权重哈希及双方关节顺序。原生推理入口严格加载；官方critic、优化器和课程状态不会伪造或静默补齐。

从头训练入口为 `ame-train --variant ame2-gaze --phase base`，配置继承官方 teacher 配方。应显式设置环境数和训练预算；默认 5,000 次更新不构成效果保证。正式训练须通过上述行为与集成检查。原生 Gaze 训练保存的完整 checkpoint 可用于同任务续训；模型、优化器、熵系数和全局课程时钟恢复不等于逐环境物理状态及地形 EMA 的逐位恢复。
